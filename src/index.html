A FEW THINGS TO KNOW

开始之前，你可能还想知道

原版 CrossMux 可以直接安装这些应用吗？

暂时不可以。Lua 运行时、应用管理和权限接口目前在 CrossStore 固件分支中，需要先安装支持它们的固件；后续是否进入官方主分支，以维护者的讨论和合并结果为准。

Mac、Windows、Linux 都能刷吗？

使用支持 Web Serial 的桌面版 Chrome 或 Edge，通过 HTTPS 打开本站即可。Safari、Firefox 和大部分手机浏览器不支持；可改用桌面浏览器，或下载镜像使用本地刷机工具。

刷机和下载应用会依赖 GitHub 网络吗？

本页固件与刷机代码都由本站提供，不需要从第三方 CDN 加载。本站和默认应用目录仍托管于 GitHub Pages，网络不稳定时可能需要重试。已安装的离线应用不依赖商店连接。

应用的权限与安装包安全吗？

应用会声明文件、网络、音频等权限，安装前请核对。当前是开发预览：安装包尚未签名，设备端的 HTTPS 证书校验仍待完善；请只使用你信任的目录。网页刷机前会核对固件大小与 SHA-256，但这不等同于设备端包签名验证。

为什么有些设备不能收音机播放或 LoRa 聊天？

能力取决于硬件和底层适配。PaperMono 使用蜂鸣器，不能期待正常扬声器的音乐表现；Waveshare 的 AirTune 响度仍待优化。rf_chat 需要兼容的 LoRa 硬件。商店会检查应用声明的能力需求。

能把应用提交到商店吗？

欢迎！在 CrossStore 仓库的 packages 目录中提交 Lua 应用、元信息、权限和硬件需求、图标及说明，再发起 PR。参考现有包及仓库文档，先在目标设备上验证。
