开源致谢

CrossStore 建立在社区项目之上，感谢参与固件、设备驱动与工具维护的开发者。

  • CrossMux 与 CrossPoint Reader：阅读器与固件基础。
  • FreeInk SDK：硬件抽象和设备驱动。
  • CrossStore：Lua 应用、商店图标与应用图标。本网站复用的图标遵循仓库所附 MIT 许可。
  • ESP Web Tools 与 esptool-js：浏览器串口连接与固件刷写。许可：ESP Web Tools、esptool-js、pako、tslib、atob-lite。

本网站为社区预览项目，不代表上述项目或设备厂商的官方发布。固件的来源、版本及校验值见 发布记录；设备与应用的商标归各自所有者。
